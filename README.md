## Writing a Data Management Plan for Tri-Agency Grant Applications
### What's new in the UVic DMP Template

UVic Libraries slide deck on writing data management plans (DMPs) under the Tri-Agency Research Data Management Policy, using the [DMP Assistant](https://dmp-pgd.ca/). Most of the deck covers the 2026 revisions to the University of Victoria DMP Template and how they respond to feedback from user focus groups.

Built with [reveal.js](https://revealjs.com/) (vendored in `reveal/`, MIT licence). Open `index.html` in a browser, or enable GitHub Pages on the `main` branch. Press `s` for speaker notes.
